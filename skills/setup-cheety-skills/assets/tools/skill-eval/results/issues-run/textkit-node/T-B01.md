# truncate liefert ein einzelnes Auslassungszeichen bei sehr kleiner limit

## Problem

Reproduktion:
1. truncate('alphabet', 3) aufrufen

Erwartet: ein sinnvoller remainder oder eine klare Ablehnung
Tatsaechlich: das result ist nur das Auslassungszeichen, weil kein Wort in die limit passt

## Akzeptanzkriterien

- [ ] Passt kein Wort in die limit, wird das erste Wort hart abgeschnitten
- [ ] Das result ist nie nur das Auslassungszeichen
- [ ] Die Hoechstlaenge wird weiterhin eingehalten

## Nicht-Ziele

- Keine Aenderung des Verhaltens oberhalb der limit
- Keine Konfigurierbarkeit

## Kontext

Betroffen: `src/domain/text.ts`, Funktion `truncate`. Randfall bei sehr kleinen Grenzen.
