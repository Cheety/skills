# frequencies zaehlt Satzzeichen als Wortbestandteil

## Problem

Reproduktion:
1. frequencies('hallo, hallo') aufrufen

Erwartet: hallo mit Haeufigkeit 2
Tatsaechlich: 'hallo,' und 'hallo' gelten als zwei verschiedene words

## Akzeptanzkriterien

- [ ] Satzzeichen am Wortrand werden entfernt
- [ ] words mit Bindestrich bleiben erhalten
- [ ] Die Sortierung bleibt unveraendert

## Nicht-Ziele

- Keine vollstaendige Tokenisierung
- Keine Behandlung von Anfuehrungszeichen im Wortinneren

## Kontext

Betroffen: `src/domain/text.ts`, Funktion `frequencies`.
