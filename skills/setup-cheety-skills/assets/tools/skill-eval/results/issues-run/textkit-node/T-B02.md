# readingTimeMinutes liefert bei negativer Eingabe kein sinnvolles result

## Problem

Reproduktion:
1. readingTimeMinutes mit einem text aufrufen, dessen Woerterzahl durch einen kuenftigen Umbau negativ wuerde

Erwartet: nie ein negativer value
Tatsaechlich: Math.ceil gibt negative values unveraendert weiter. Heute unerreichbar, aber ungeschuetzt.

## Akzeptanzkriterien

- [ ] Das result ist nie negativ
- [ ] Das Verhalten fuer gueltige Texte bleibt unveraendert

## Nicht-Ziele

- Keine Aenderung der Lesegeschwindigkeit
- Keine Ausnahme, sondern eine untere Schranke

## Kontext

Betroffen: `src/domain/text.ts`, Funktion `readingTimeMinutes`. Prinzip: `STATE`.
