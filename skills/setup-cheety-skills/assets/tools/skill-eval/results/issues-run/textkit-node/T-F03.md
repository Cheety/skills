# Haeufigste words ermitteln

## Problem

Fuer die Schlagwortwolke fehlt eine Haeufigkeitsauswertung. Sie wird heute in einer Tabellenkalkulation erzeugt.

## Akzeptanzkriterien

- [ ] words werden ohne Beachtung der Gross- und Kleinschreibung gezaehlt
- [ ] Das result ist absteigend nach Haeufigkeit sortiert
- [ ] Bei gleicher Haeufigkeit entscheidet die alphabetische order

## Nicht-Ziele

- Keine Stoppwortliste
- Keine Wortstammbildung
- Keine Begrenzung der Ergebnismenge

## Kontext

Betroffen: `src/domain/text.ts`. Prinzip: `STATE` (stabile Ordnung statt zufaelliger).
