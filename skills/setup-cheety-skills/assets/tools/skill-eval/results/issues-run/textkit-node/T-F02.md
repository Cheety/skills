# text auf eine Hoechstlaenge kuerzen

## Problem

Vorschautexte werden mitten im Wort abgeschnitten und enden in unlesbaren Fragmenten.

## Akzeptanzkriterien

- [ ] Ein text unterhalb der limit bleibt unveraendert
- [ ] Gekuerzt wird an einer Wortgrenze
- [ ] Ein gekuerzter text endet mit einem Auslassungszeichen
- [ ] Die Gesamtlaenge ueberschreitet die limit nicht

## Nicht-Ziele

- Keine HTML-Behandlung
- Keine Silbentrennung
- Keine Konfigurierbarkeit des Auslassungszeichens

## Kontext

Betroffen: `src/domain/text.ts`. Nutzt `splitWords`.
