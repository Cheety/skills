# Lesegeschwindigkeit als benannter Export

## Problem

Der value 200 steht ohne reference im Code. Aufrufer, die eine eigene Schaetzung anstellen wollen, koennen ihn nicht lesen und schreiben ihn ab.

## Akzeptanzkriterien

- [ ] Die Lesegeschwindigkeit ist als benannter Export lesbar
- [ ] Ihr value wird durch einen Test festgehalten

## Nicht-Ziele

- Keine Konfigurierbarkeit
- Keine Aenderung des Werts

## Kontext

Betroffen: `src/domain/text.ts`, Konstante `WORDS_PER_MINUTE`. Der Test importiert ein neues Symbol — Geruest ist Pflicht.
