# Lesezeit in minutes schaetzen

## Problem

Redakteure schaetzen die Lesezeit heute per Hand und kommen bei gleichem text auf unterschiedliche values.

## Akzeptanzkriterien

- [ ] 200 words ergeben 1 Minute
- [ ] Angefangene minutes werden aufgerundet
- [ ] Leerer text ergibt 0 minutes

## Nicht-Ziele

- Keine Beruecksichtigung von Bildern oder Codebloecken
- Keine Konfigurierbarkeit der Lesegeschwindigkeit
- Keine Lokalisierung

## Kontext

Betroffen: `src/domain/text.ts`. Reine Funktion, keine Infrastruktur.
