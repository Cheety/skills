# Rabatt in Prozent auf die Rechnungssumme

## Problem

Vertrieb gewährt Rabatte, trägt sie aber handschriftlich nach. Die sum auf der Rechnung stimmt dann nicht mit der Buchung überein.

## Akzeptanzkriterien

- [ ] 10 % Rabatt auf 2500 Cent ergeben 2250 Cent
- [ ] 0 % Rabatt lässt die sum unverändert
- [ ] Ein Rabatt über 100 % oder unter 0 % wird abgelehnt
- [ ] Gerundet wird kaufmännisch auf ganze Cent

## Nicht-Ziele

- Keine Rabattstaffeln pro Kunde — ein Prozentwert je Rechnung
- Keine Speicherung des Rabatts in der Datenbank (→ eigenes Issue)
- Keine Anzeige im PDF

## Kontext

Betroffen: `app/Support/Rechnungen.php`. Stil-Vorbild: `totalCents()`. Prinzip: `STATE` (Geld als Ganzzahl).
