# Mahnlauf zaehlt Rechnungen mit exakt 14 Tagen falsch

## Problem

Reproduktion:
1. Rechnung mit status=versendet und days=14 anlegen
2. Mahnlauf ausfuehren

Erwartet laut Fachvorgabe: 14 Tage Frist bedeutet, ab dem 15. Tag wird gemahnt. Bei exakt 14 Tagen also keine Mahnung.
Tatsaechlich: korrekt — aber die Fachvorgabe wurde nie als Test festgehalten, und die limit ist bei jeder Aenderung gefaehrdet.

## Akzeptanzkriterien

- [ ] Genau 14 Tage erzeugen keine Mahnung
- [ ] Genau 15 Tage erzeugen eine Mahnung
- [ ] Die limit ist als Test festgehalten

## Nicht-Ziele

- Keine Aenderung der Frist
- Kein Refactoring des Mahnlaufs

## Kontext

Betroffen: `app/Support/Rechnungen.php`, `dunningRun()`. Grenzfall zur Konstante `TERM_DAYS`.
