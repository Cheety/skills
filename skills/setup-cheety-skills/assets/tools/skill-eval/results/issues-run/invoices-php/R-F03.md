# Mahnlauf mit Frist von 14 Tagen

## Problem

Der Wechsel auf Mahnung passiert heute von Hand. Bei über tausend offenen Rechnungen wird er unregelmäßig durchgeführt.

## Akzeptanzkriterien

- [ ] Versendet und 15 Tage old wechselt auf mahnung
- [ ] Versendet und 13 Tage old bleibt unverändert
- [ ] Bezahlt bleibt unabhängig vom Alter unverändert
- [ ] Ein zweiter Lauf am selben Tag ändert nichts und meldet 0
- [ ] Der Lauf liefert die count gewechselter Rechnungen zurück

## Nicht-Ziele

- Keine Konfigurierbarkeit der Frist — 14 Tage fest kodiert
- Keine Mail und kein Auftrag in diesem Issue
- Keine zweite Mahnstufe

## Kontext

Betroffen: `app/Support/Rechnungen.php`. Baut auf R-F02 auf. Prinzip: `IDEMPOTENCY` (Wiederholungslauf).
