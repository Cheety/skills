# Mahnlauf liefert strukturiertes result statt Tupel

## Problem

Der Rueckgabewert [array, int] zwingt jeden Aufrufer zum Auspacken in der richtigen order. Ein vertauschtes Paar faellt erst zur Laufzeit auf.

## Akzeptanzkriterien

- [ ] Der Lauf liefert ein Objekt mit benannten Feldern rechnungen und anzahl
- [ ] Die bestehenden Fachregeln bleiben unveraendert
- [ ] Das Ergebnisobjekt ist immutable

## Nicht-Ziele

- Keine Aenderung der Mahnlogik
- Keine neue Abhaengigkeit

## Kontext

Betroffen: `app/Support/Rechnungen.php`, `dunningRun()`. Prinzip: `IMMUTABILITY`.
