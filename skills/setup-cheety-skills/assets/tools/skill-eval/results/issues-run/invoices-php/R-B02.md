# Unbekannter Zustand wird stillschweigend als valid behandelt

## Problem

Reproduktion:
1. canTransitionTo('tippfehler', 'bezahlt') aufrufen

Erwartet: Fehler, der Zustand existiert nicht
Tatsaechlich: liefert false wie ein regulaerer verbotener transition. Ein Tippfehler im status ist damit nicht von einer Fachregel unterscheidbar.

## Akzeptanzkriterien

- [ ] Ein unbekannter Ausgangszustand wirft eine Ausnahme
- [ ] Ein unbekannter Zielzustand wirft eine Ausnahme
- [ ] Bekannte Zustaende verhalten sich unveraendert

## Nicht-Ziele

- Keine Umstellung auf ein Enum in diesem Issue
- Keine Aenderung der Uebergangstabelle

## Kontext

Betroffen: `app/Support/Rechnungen.php`, `canTransitionTo()`. Der `?? []`-Ausdruck verschluckt den Fehler. Prinzip: `ERRORS`.
