# Negative Mengen erzeugen negative Rechnungssummen

## Problem

Reproduktion:
1. Posten mit Menge -2 und Einzelpreis 1000 anlegen
2. sum berechnen

Erwartet: Ablehnung
Tatsaechlich: sum -2000 Cent, die Rechnung wird zur Gutschrift

## Akzeptanzkriterien

- [ ] Menge kleiner 1 wird abgelehnt
- [ ] Negativer Einzelpreis wird abgelehnt
- [ ] Gueltige Posten verhalten sich unveraendert

## Nicht-Ziele

- Keine Gutschriftenfunktion in diesem Issue
- Kein Refactoring der Summenlogik

## Kontext

Betroffen: `app/Support/Rechnungen.php`, `totalCents()`.
