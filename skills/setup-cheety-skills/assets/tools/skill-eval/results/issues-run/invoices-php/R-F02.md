# Mahnstatus als eigener Zustand

## Problem

Überfällige Rechnungen sind nicht von versendeten unterscheidbar. Die Buchhaltung führt eine getrennte Liste.

## Akzeptanzkriterien

- [ ] versendet darf nach mahnung wechseln
- [ ] mahnung darf nach bezahlt und storniert wechseln
- [ ] mahnung darf nicht zurück nach versendet
- [ ] Kein Zustand erlaubt einen Übergang auf sich selbst

## Nicht-Ziele

- Kein automatischer Lauf — nur der Zustand (→ R-F03)
- Keine Mahngebühren
- Keine Mail

## Kontext

Betroffen: `app/Support/Rechnungen.php`, Konstante `TRANSITIONS`. Prinzip: `STATE`.
