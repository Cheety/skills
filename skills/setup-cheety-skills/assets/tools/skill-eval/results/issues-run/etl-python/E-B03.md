# group_by_key uebernimmt unplausible Betraege ungefiltert

## Problem

Reproduktion:
1. Eine Zeile mit amount 200_000_000 und eine gueltige Zeile gruppieren

Erwartet: die unplausible Zeile taucht in der Gruppierung nicht auf
Tatsaechlich: sie wird mitsummiert. Die Plausibilitaetspruefung aus E-F03 wird nicht angewandt.

## Akzeptanzkriterien

- [ ] Unplausible Zeilen werden vor der Gruppierung entfernt
- [ ] Die Summen gueltiger Zeilen bleiben unveraendert

## Nicht-Ziele

- Keine Meldung der aussortierten Zeilen aus group_by_key heraus
- Keine Aenderung der Grenzen

## Kontext

Betroffen: `src/domain/pipeline.py`, `group_by_key`. Nutzt `check_plausible` aus E-F03.
