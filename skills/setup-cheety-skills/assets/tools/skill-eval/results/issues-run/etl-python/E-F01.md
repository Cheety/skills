# Doppelte Kennungen erkennen

## Problem

Der Import laedt taeglich dieselbe Datei erneut, wenn der Upload wiederholt wird. Doppelte Kennungen landen unbemerkt in der Auswertung.

## Akzeptanzkriterien

- [ ] Zwei Zeilen mit gleicher normalisierter identifier werden als Duplikat gemeldet
- [ ] Unterschiedliche Schreibweisen derselben identifier gelten als Duplikat
- [ ] Eine leere Eingabe liefert eine leere Duplikatliste

## Nicht-Ziele

- Kein Entfernen der duplicates — nur Meldung
- Keine Persistenz
- Keine Konfigurierbarkeit der Normalisierung

## Kontext

Betroffen: `src/domain/pipeline.py`. Prinzip: `IDEMPOTENCY`.
