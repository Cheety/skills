# normalise scheitert an None statt eine klare Meldung zu geben

## Problem

Reproduktion:
1. normalise(None) aufrufen

Erwartet: klare Fehlermeldung mit reference zur identifier
Tatsaechlich: AttributeError tief in der Standardbibliothek, ohne Hinweis auf die Quellzeile

## Akzeptanzkriterien

- [ ] None wirft einen ValueError mit sprechender Meldung
- [ ] Ein leerer String wirft ebenfalls
- [ ] Gueltige Kennungen verhalten sich unveraendert

## Nicht-Ziele

- Keine Typpruefung zur Laufzeit fuer alle Felder
- Keine Aenderung der Normalisierungsregel

## Kontext

Betroffen: `src/domain/pipeline.py`, `normalise`. Prinzip: `ERRORS`.
