# Zeilen mit unplausiblen Betraegen aussortieren

## Problem

Einzelne Quellzeilen enthalten Betraege jenseits jeder Plausibilitaet, meist durch fehlerhafte Spaltentrennung. Sie verzerren die Auswertung.

## Akzeptanzkriterien

- [ ] Betraege ueber 100 Millionen Cent werden rejected
- [ ] Negative Betraege werden rejected
- [ ] Die Funktion liefert gueltige und aussortierte Zeilen getrennt zurueck

## Nicht-Ziele

- Keine Korrektur der Zeilen
- Keine Protokollierung in eine Datei
- Keine Konfigurierbarkeit der limit

## Kontext

Betroffen: `src/domain/pipeline.py`. Prinzip: `ERRORS` (laut aussortieren statt still verwerfen).
