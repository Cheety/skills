# can_transition erlaubt den transition eines Zustands auf sich selbst nicht, meldet ihn aber wie einen Fachfehler

## Problem

Reproduktion:
1. can_transition('new', 'new') aufrufen

Erwartet: klare Aussage, dass Selbstuebergaenge grundsaetzlich unzulaessig sind
Tatsaechlich: liefert False wie jeder andere verbotene transition. Ein Aufrufer, der Selbstuebergaenge als Sonderfall behandeln will, kann sie nicht erkennen.

## Akzeptanzkriterien

- [ ] Ein self transition wird als solcher erkennbar gemeldet
- [ ] Regulaere verbotene Uebergaenge bleiben unveraendert False
- [ ] Erlaubte Uebergaenge bleiben unveraendert True

## Nicht-Ziele

- Keine Ausnahme statt False
- Keine Aenderung der Uebergangstabelle

## Kontext

Betroffen: `src/domain/order.py`, `can_transition`. Der Test importiert ein neues Symbol — Geruest ist Pflicht.
