# check_refund akzeptiert Auftraege in unzulaessigem Zustand

## Problem

Reproduktion:
1. Auftrag im Zustand 'new' anlegen
2. check_refund mit gueltigem amount aufrufen

Erwartet: Ablehnung, weil noch nichts bezahlt wurde
Tatsaechlich: die Pruefung betrachtet nur den amount, nicht den Zustand

## Akzeptanzkriterien

- [ ] Eine Erstattung ist nur aus dem Zustand bezahlt zulaessig
- [ ] Aus jedem anderen Zustand wird abgelehnt
- [ ] Die Betragspruefungen bleiben unveraendert

## Nicht-Ziele

- Keine Aenderung der Zustandstabelle
- Keine Teilerstattung

## Kontext

Betroffen: `src/domain/order.py`, `check_refund`. Nutzt `can_transition`.
