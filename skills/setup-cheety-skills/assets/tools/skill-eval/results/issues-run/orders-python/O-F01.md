# Erstattung nur bis zum vollen amount

## Problem

Der Kundendienst erstattet gelegentlich mehr als bezahlt wurde. Die Abweichung faellt erst im Monatsabschluss auf.

## Akzeptanzkriterien

- [ ] Eine Erstattung bis zum Auftragsbetrag ist zulaessig
- [ ] Eine Erstattung ueber den amount hinaus wird abgelehnt
- [ ] Eine Erstattung von null wird abgelehnt

## Nicht-Ziele

- Keine Teilerstattungshistorie
- Keine Waehrungsumrechnung
- Keine Buchung

## Kontext

Betroffen: `src/domain/order.py`. Prinzip: `STATE`.
