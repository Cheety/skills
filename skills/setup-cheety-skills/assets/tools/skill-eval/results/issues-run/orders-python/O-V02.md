# Verarbeitete Ereignisse zaehlbar machen

## Problem

Der Handler fuehrt die verarbeiteten Kennungen in einem Modul-Set. Fuer die Beobachtbarkeit fehlt eine Zaehlung; Aufrufer greifen heute direkt auf das Set zu.

## Akzeptanzkriterien

- [ ] Eine Funktion liefert die count verarbeiteter Ereignisse
- [ ] Nach dem Zuruecksetzen ist die count null

## Nicht-Ziele

- Keine Persistenz
- Keine Metrik-Anbindung

## Kontext

Betroffen: `src/jobs/payment_received.py`. Neues Symbol — Geruest ist Pflicht.
