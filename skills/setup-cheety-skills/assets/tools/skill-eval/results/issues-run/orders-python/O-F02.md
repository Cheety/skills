# Endzustaende ausweisen

## Problem

Auswertungen muessen heute die Uebergangstabelle nachbilden, um abgeschlossene Auftraege zu erkennen.

## Akzeptanzkriterien

- [ ] Ein Zustand ohne Folgezustaende gilt als terminal state
- [ ] new und bezahlt sind keine Endzustaende
- [ ] Ein unbekannter Zustand wirft

## Nicht-Ziele

- Keine Aenderung der Uebergaenge
- Keine neue Zustandsart

## Kontext

Betroffen: `src/domain/order.py`.
