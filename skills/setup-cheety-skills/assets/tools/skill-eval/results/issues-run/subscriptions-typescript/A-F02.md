# Upgrade-difference beim Stufenwechsel

## Problem

Beim Wechsel auf eine hoehere Stufe wird heute der volle neue Monatspreis berechnet, obwohl der laufende Monat schon bezahlt ist.

## Akzeptanzkriterien

- [ ] Wechsel von basis auf pro kostet die difference von 4000 Cent
- [ ] Ein Wechsel auf dieselbe Stufe kostet 0
- [ ] Ein Downgrade kostet 0 und erstattet nichts

## Nicht-Ziele

- Keine taggenaue Anteilsrechnung
- Keine Erstattung bei Downgrade
- Keine Aenderung der Preistabelle

## Kontext

Betroffen: `src/domain/abo.ts`. Baut auf `isHigherTier` auf.
