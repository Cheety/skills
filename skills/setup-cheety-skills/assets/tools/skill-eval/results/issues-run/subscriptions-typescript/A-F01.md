# annual price mit zwei Freimonaten

## Problem

Kunden fragen nach Jahreszahlung. Der Vertrieb rechnet den Rabatt heute im Kopf und kommt auf unterschiedliche Betraege.

## Akzeptanzkriterien

- [ ] annual price entspricht zehn Monatspreisen
- [ ] basis kostet jaehrlich 9000 Cent
- [ ] Der value ist eine Ganzzahl in Cent

## Nicht-Ziele

- Keine Zahlungsabwicklung
- Keine anteilige Erstattung bei Kuendigung
- Keine Konfigurierbarkeit der Freimonate

## Kontext

Betroffen: `src/domain/abo.ts`. Prinzip: `STATE` (Geld als Ganzzahl).
