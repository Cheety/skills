# Upgrade-difference akzeptiert unbekannte Stufen still

## Problem

Reproduktion:
1. upgradeDeltaCents mit einem Tippfehler als Stufe aufrufen

Erwartet: Fehler
Tatsaechlich: undefined in der Rechnung, result NaN oder 0 — je nach Pfad. Der Tippfehler faellt nie auf.

## Akzeptanzkriterien

- [ ] Eine unbekannte Ausgangsstufe wirft einen Fehler
- [ ] Eine unbekannte Zielstufe wirft einen Fehler
- [ ] Bekannte Stufen verhalten sich unveraendert

## Nicht-Ziele

- Keine Umstellung auf ein Schema-Werkzeug
- Keine Aenderung der Rangtabelle

## Kontext

Betroffen: `src/domain/abo.ts`, Funktion `upgradeDeltaCents`. Prinzip: `ERRORS`.
