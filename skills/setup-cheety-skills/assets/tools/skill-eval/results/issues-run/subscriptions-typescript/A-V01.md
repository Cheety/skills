# Preisreihenfolge und Rangreihenfolge sind deckungsgleich

## Problem

Nach A-B01 gibt es zwei Ordnungen: price und rank. Sie stimmen heute ueberein, aber nichts stellt das sicher. Eine Preisaktion koennte sie auseinanderlaufen lassen, ohne dass es auffaellt.

## Akzeptanzkriterien

- [ ] Ein Test haelt fest, dass hoeherer rank auch hoeheren price bedeutet
- [ ] Der Test bricht, sobald eine Preisaenderung die Ordnung verletzt

## Nicht-Ziele

- Keine Zusammenfuehrung von price und rank
- Keine Aenderung der Preistabelle

## Kontext

Betroffen: `src/domain/abo.ts`. Regressionsschutz fuer A-B01.
