# Preistabelle gegen Veraenderung schuetzen

## Problem

PRICE_CENTS ist exportiert und veraenderbar. Ein Aufrufer kann die Preise zur Laufzeit ueberschreiben; der Fehler faellt erst in der Abrechnung auf.

## Akzeptanzkriterien

- [ ] Ein Schreibversuch auf die Preistabelle scheitert
- [ ] Die Lesezugriffe bleiben unveraendert

## Nicht-Ziele

- Keine Kapselung hinter einer Funktion
- Keine Aenderung der values

## Kontext

Betroffen: `src/domain/abo.ts`, Konstante `PRICE_CENTS`. Prinzip: `IMMUTABILITY`.
