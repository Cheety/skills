# annual price rundet bei ungeraden Monatspreisen nicht

## Problem

Reproduktion:
1. Eine Stufe mit Monatspreis 999 Cent annehmen
2. annual price berechnen

Erwartet: ganzzahliges result in Cent
Tatsaechlich: korrekt bei ganzzahliger Multiplikation, aber es fehlt jede Zusicherung. Sobald jemand einen Faktor mit Nachkommastellen einfuehrt, entstehen Bruchteile von Cent.

## Akzeptanzkriterien

- [ ] Der annual price ist immer eine Ganzzahl
- [ ] Ein nicht ganzzahliges Zwischenresults wird gerundet, nicht abgeschnitten

## Nicht-Ziele

- Keine Aenderung der Freimonate
- Keine neue Preisstufe

## Kontext

Betroffen: `src/domain/abo.ts`, Funktion `annualPriceCents`. Prinzip: `STATE`.
