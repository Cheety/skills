# Stufenbeschreibung fuer die Oberflaeche

## Problem

Die Oberflaeche zeigt den technischen Schluessel 'basis' statt eines lesbaren Namens.

## Akzeptanzkriterien

- [ ] Jede Stufe liefert einen lesbaren Namen
- [ ] Ein neuer Enum-Fall bricht die Uebersetzung statt still in einen Auffangzweig zu laufen

## Nicht-Ziele

- Keine Mehrsprachigkeit
- Keine Formatierung des Preises
- Keine Aenderung der Stufen

## Kontext

Betroffen: `src/domain/abo.ts`. Prinzip: `STATE` (Vollstaendigkeit ohne Auffangzweig).
