# Rechnungswesen, Entwurf

Ein Dokument mit gueltigem Frontmatter und ohne einen einzigen Meilenstein. Es
sieht aus wie ein Fahrplan und ist eine Absichtserklaerung — genau der Zustand,
der sonst monatelang unbemerkt bleibt, weil ein Pruefer ohne Befunde nicht von
einem sauberen Dokument zu unterscheiden ist.

Dateiweite Befunde werden auf der letzten Zeile gemeldet, weil Zeile 1 der
Frontmatter-Zaun ist und keinen Marker tragen kann.
